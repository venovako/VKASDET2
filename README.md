# VKASDET2
Vectorizable Kahan's Algorithm with Scaling for Determinants of order two

(... work in progress ...)

Requires [libpvn](https://github.com/venovako/libpvn) with the optional [GMP](https://gmplib.org) and [MPFR](https://mpfr.org) support enabled on an `AVX512F`-compatible system with either `icx` or `gcc`.

See the examples in `src/build_pvn-icx.sh` and `src/build_pvn-gcc.sh`.

This work has been supported in part by Croatian Science Foundation under the project IP-2014-09-3670 ([MFBDA](https://web.math.pmf.unizg.hr/mfbda/)).
